How it works.

Rate every team

An Elo rating moves after each result, with a home-field bonus. It replays six seasons of real Premier League results in order.

Add recent form

Goals scored, goals conceded and points over each side's last five matches, computed before kick-off so nothing leaks from the future.

Fit and score

A multinomial logistic regression turns nine features into home, draw and away probabilities. XGBoost was tried too and did worse.

Run in your browser

The fitted coefficients ship as a small JSON file, so this page computes the same probabilities as the Python model with no server.
